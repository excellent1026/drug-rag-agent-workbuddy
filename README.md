# 循证用药科普 RAG Agent

> 基于 WorkBuddy + LangChain + IMA 向量知识库搭建的医药科普智能问答项目
> 面向普通用户，提供合规、安全的用药知识科普，不提供处方、不替代医师诊断

## ✨ 项目简介

本项目构建循证用药知识库，利用RAG检索增强生成 + Agent编排，对用户用药问题做专业内容解读，自动加上安全免责提示。
知识库内容包含通用用药原则、常用外用/口服药物科普、不良反应识别、用药禁忌等循证科普文本。

> ⚠️ 本项目仅用于科普演示，所有输出不能作为诊疗依据。

## 🛠️ 技术栈

- LangChain：RAG检索链路封装
- WorkBuddy：Agent编排、提示词管理、工作流调度
- IMA知识库：向量存储、文本向量化检索
- Redis：检索缓存，提升问答响应速度
- Java SpringBoot：后端接口服务
- Markdown：项目文档

## 📁 项目架构

用户提问 → Agent接收问题 → IMA知识库向量检索相关片段 → 提示词组装 → LLM生成科普回答 → 添加安全边界提示 → 返回结果

## 📖 功能说明

1. 检索知识库内已有的用药知识，用通俗语言做科普解读
2. 内置安全约束：不会给出个体化用药方案、不开处方
3. 知识库不存在的药品，主动告知暂无相关资料，不编造信息
4. 自动识别高危提问，输出免责提示

## 🚀 项目启动

1. 在 ima.qq.com 登录账号，上传循证用药科普知识库文本，等待向量解析完成
2. WorkBuddy中创建Agent，配置科普解读提示词，绑定IMA知识库
3. 启动SpringBoot后端服务，对接WorkBuddy Agent接口
4. 在Agent对话窗口发起提问，验证RAG检索效果

## 📌 项目亮点

1. 医药场景RAG，设置严格的回答边界，规避医疗风险
2. 可扩展：后续可以继续上传官方药品PDF、临床指南扩充知识库
3. Agent工作流解耦，检索模块和生成模块分离，方便迭代优化
