阶段 1 · 知识库规划清单
项目：循证用药科普 RAG 智能Agent 定位红线：仅做药品科普、说明书信息检索、禁忌/不良反应解读、多药联用风险提示；严禁疾病诊断、不替代医生药师、不给出诊疗方案。 本清单可直接执行，用于指导「资料收集 → 命名归档 → 切片 → 打标签」全流程。

一、要收集的文档类型 + 收集渠道（全部公开、免费、合规）
A 类 · 药品说明书（核心素材，占知识库约 70%）
类型	说明	推荐渠道
化学药 / 生物药说明书	国家药监局核准的公开说明书	国家药监局官网（nmpa.gov.cn）药品数据库、说明书修订公告；丁香园用药助手公开说明书库；药智数据免费公开部分
中成药说明书	成分、禁忌、不良反应	同上，优先国家药监局公开版
处方药 / OTC 说明书	覆盖慢病常用药	各公开说明书库，以「国家药监局核准版本」为准
合规要求：只收集公开可免费获取的说明书；优先以国家药监局核准版本为准，避免使用来源不明的第三方改写版。

B 类 · 权威慢病科普指南（占知识库约 30%）
类型	示例	推荐渠道
国家发布的诊疗/管理指南	高血压、2型糖尿病、血脂异常、慢阻肺等防治指南	国家卫生健康委官网；中华医学会系列期刊公开指南；中国医师协会、各专科学会官网公开版
专家共识 / 用药指导	用药安全、合理用药共识	学会官网、正规医学期刊公开全文
权威机构科普	WHO、国家慢病中心公开科普	世界卫生组织中文资料、中国疾控中心官网
合规要求：只收集免费公开全文；需注册/付费的期刊文章一律跳过，宁缺毋滥。

建议的「最小可执行包」（先跑通流程，再扩量）
药品说明书：选 15~20 个慢病常用药（降压、降糖、调脂、抗凝、呼吸），优先覆盖「药物相互作用」章节完整的品种。
慢病指南：高血压、2型糖尿病、血脂异常各 1 份，共 3 份。
跑通后再批量扩充。
二、命名规范 + 文件夹分类结构
文件命名规范（三段式，避免空格和特殊字符）
药品说明书：  {通用名}_{剂型规格}_{版本年份}_{来源}.pdf
示例：        阿司匹林_肠溶片100mg_2023_NMPA.pdf

指南/共识：   {指南名称缩写}_{年份}_{发布机构}.pdf
示例：        中国高血压防治指南_2024_中华医学会.pdf
命名要点：统一用下划线分隔；版本年份用核准/发布年份；来源用机构缩写（NMPA / 中华医学会 / WHO 等）。

三、切片规则（适配药品说明书长文本）
药品说明书是「强结构化长文本」，自带章节标题，因此优先结构化切分，而不是固定长度盲切。

推荐参数（可直接使用）
参数	药品说明书	指南/长文档
切分方式	优先按章节标题【适应症】【不良反应】【禁忌】【药物相互作用】等切	优先按一/二级标题切
chunk_size	600 字符	800 字符
chunk_overlap	80 字符（约 13%）	100 字符
二次切分	单章节超过 700 字符时，按 600/80 继续切	同左
检索 top_k	5~8	5~8
切片规则要点
每个 chunk 保留上下文前缀：【药品通用名】【章节标题】，例如 【阿司匹林肠溶片】【不良反应】…，避免切碎后语义丢失。
说明书章节标题清单（作为切分锚点）：药品名称、成份、适应症、用法用量、不良反应、禁忌、注意事项、药物相互作用、药理毒理、贮藏、有效期。
药物相互作用章节是联用核验 Agent 的关键，务必完整保留、单独成块。
重叠窗口用于防止「不良反应」等跨段内容被切断，80 字符约覆盖 1~2 个完整句子。
四、元数据标签方案（供检索 Agent 精准过滤）
每个 chunk / 文档打以下标签，后续检索 Agent 可按标签过滤。

字段表

检索过滤映射（关键用法）
用户问「XX 有什么副作用」 → 过滤 section=不良反应
用户问「XX 和 YY 能一起吃吗」 → 过滤 section=药物相互作用 且 drug_pair 含两者
用户问「XX 哪些人不能用」 → 过滤 section=禁忌
五、禁止幻觉强制规则
这是全项目的硬性规则，写入每个 Agent 的 Prompt 和工作流护栏。

处处标注出处：每个结论必须标注「文档名称 + 章节」，例如 （来源：《阿司匹林肠溶片说明书》【不良反应】章节）；引用原文时注明段落。
无资料即拒绝：知识库检索不到对应权威信息时，一律回复：
暂无相关权威资料，无法解答。建议咨询执业医师或药师。

禁止编造：禁止用模型内部知识补全知识库没有的内容，禁止虚构出处、页码、数据。
出处真实可溯：标注的文档名、章节必须是知识库中真实存在的，不得凭空生成。
不确定就说不知道：信息模糊或版本存疑时，明确告知「以最新版说明书为准」，而不是给出确定结论。
六、执行清单（Checklist，照着打勾即可）
 建好 knowledge_base/ 目录结构（四个子文件夹 + README）
 收集 15~20 份说明书，按命名规范重命名，归入对应治疗领域文件夹
 收集 3 份核心慢病指南，归入 02_慢病科普指南/
 在 README 记录：知识库范围、来源、版本、更新日期
 确定切片工具/平台，按「结构化切分 + 600/80」执行
 为每个 chunk 打元数据标签，导出 04_元数据索引/metadata.json
 抽样 3~5 个问题做召回测试，验证「章节过滤」是否命中正确内容
 把「禁止幻觉规则」同步写入后续每个 Agent 的 Prompt
